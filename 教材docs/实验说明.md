# 实验说明：教材案例的 Python 迁移

本文逐章说明教材案例的业务内涵、迁移到 Python 的对应做法与运行结论，配合各脚本顶部注释阅读。
教材原始实现以 Power BI / Excel 为主，资料包内没有 .ipynb 文件，因此全部案例都走“Excel/Power BI → Python”这一条迁移路径。

## 0. 迁移方法总览

| 教材 / Power BI / Excel 中的操作 | 本项目的 Python 对应 |
| --- | --- |
| Power Query 清洗、逆透视、合并查询 | `pandas.read_excel / read_csv`、`melt`、`merge`、`str` 访问器 |
| 关系模型、基数和筛选方向 | 显式主键校验 + `merge`，必要时先聚合再连接 |
| 计算列 | `DataFrame.assign` / 直接赋值 |
| DAX 度量值（SUM、DIVIDE、DISTINCTCOUNT、CALCULATE） | `groupby.sum`、显式分母保护、`nunique`、布尔筛选后聚合 |
| 透视表、矩阵视觉对象 | `pivot_table`（含 `margins=True`） |
| 切片器、下钻 | 函数参数化 + 分组聚合 |
| 折线/柱形/散点/桑基等视觉对象 | `matplotlib`（桑基图为自绘贝塞尔带） |
| 回归、预测、显著性检验 | `scipy.stats`、`statsmodels` |

统一约定：所有图保存到 `outputs/figures`（110 dpi），所有表保存为 UTF-8-SIG 的 CSV 到 `outputs/tables`，便于 Excel 直接打开。

## 1. 第 1 章 数据分析思维：维度、度量与模型

### 1.1 维度与度量（`ch01/01_维度与度量.py`）

- **教材内涵**：维度是观察角度（时间、城市、产品、市场），度量是可被聚合的数值（销售额、数量、毛利）。度量的可加性决定聚合方式：销售额可按任意维度求和，毛利率必须在聚合后重新相除。
- **迁移思路**：用 `pivot_table` 复现 Power BI 的矩阵与下钻；毛利率统一写成“先汇总销售额与毛利额，再相除”，避免对行级毛利率求平均造成的辛普森悖论。
- **结论**：城市 × 类别构成、分市场销售额趋势、毛利率热力图三张图给出同一份数据的三个切面；毛利率在品牌/城市间的差异来自结构而非单纯价格。

### 1.2 星型模型（`ch01/02_星型模型.py`）

- **教材内涵**：一张事实表（销售明细）+ 多张维度表（日期、产品、品牌、类别、城市），事实表只放外键与度量，维度表放描述属性。
- **迁移思路**：教材的 Power BI 模型视图无法直接运行，改为把 Excel 宽表拆成事实/维度四张表，再用 8 项校验（事实表两个外键、产品到品牌/类别外键、日期范围、三类主键唯一）验证模型可用性；模型图用 `src/diagram.py` 绘制。
- **结论**：8 项校验全部通过；2018 年销售额 1.738 亿元、2019 年 2.363 亿元，毛利率 44.76% → 45.75%。

### 1.3 关系模型与扇出（`ch01/03_关系模型.py`）

- **教材内涵**：一对多、多对多的基数关系；客户与账户之间的多对多由 `disp` 桥接表拆成两个一对多。
- **迁移思路**：先画 ER 图，再做“错误连接 vs 正确连接”的对照实验：贷款表与交易表直接按 `account_id` 连接会产生扇出，必须先聚合到账户粒度再连接。
- **结论**：直接连接得到 5,462 行、汇总被重复累加；先聚合再连接得到 30,682 行的正确结果。这条规则同样适用于后面章节的所有合并操作。

## 2. 第 2 章 数据分析方法：六类范式与引申方法

### 2.1 波士顿矩阵（`01_波士顿矩阵.py`）

- **内涵**：以市场占有率（横轴）和销售增长率（纵轴）划分明星、金牛、问题、瘦狗四类品牌，指导资源投放。
- **迁移**：用 7、8 两个月销售额计算增长率，占有率 = 品牌销售额 / 总销售额；阈值线取总市场环比增长率与品牌平均占有率（14 个品牌即 1/14≈7.1%），散点大小表示销售额。
- **结论**：C 品牌份额 6.7%、月增长 12.1%，落在“问题品牌”象限，需要判断是投入换份额还是收缩。

### 2.2 RFM（`02_RFM.py`）

- **内涵**：用最近一次消费 R、消费频次 F、消费金额 M 给用户打分，再组合成 8 类客户，指导差异化运营。
- **迁移**：以均值为界把 R/F/M 各分成高/低（R 越小越好、F 与 M 越大越好），拼接成三位编码映射到 8 类；同时输出用户明细与类别汇总。
- **结论**：重要价值用户占 18.4% 人数、贡献 62.4% 金额，是维护重点；一般发展用户人数最多但金额贡献低。

### 2.3 用户忠诚度（`03_用户忠诚度.py`）

- **内涵**：教材用 F（购买频次）与 M（购买金额）构造忠诚度矩阵，再与满意度交叉，找出“高价值但不满”的风险人群。
- **迁移**：对销售流水按会员汇总 F/M，按教材参考阈值（F=4/7，M=3,198/5,724）划分高/中/低忠诚，再统计各层满意率；输出分层汇总、待运营人群画像。
- **结论**：高忠诚满意率 66.73%、低忠诚 74.03%，中忠诚仅 36.26%，中忠诚层是最需要干预的群体。

### 2.4 同期群（`04_同期群.py`）

- **内涵**：按用户首次登录月份分组（cohort），观察其后每个月的留存率，用于区分“产品变好”与“新用户质量变化”。
- **迁移**：取每个用户的首登月作为 cohort，计算距首登的月序号，透视成留存矩阵并画热力图。
- **结论**：留存率随注册后月数递减，早期批次与近期批次的衰减速度可直接横向比较。

### 2.5 漏斗图（`05_漏斗图.py`）

- **内涵**：把业务流程拆成有序阶段，计算相邻阶段转化率与整体转化率，定位流失最严重的环节。
- **迁移**：读取教材“演示”表复现注册→登录漏斗，再读取“练习”表构造 AARRR 五阶段漏斗，横向条形 + 转化率标注。
- **结论**：AARRR 由 100 人获取逐级降到 30 人推荐，激活到留存是主要流失段。

### 2.6 相关分析与回归（`06_相关分析.py`）

- **内涵**：用散点图看形状、用相关系数看强度、用回归看边际效应，三者缺一不可。
- **迁移**：`scipy.stats.pearsonr` + `numpy.polyfit` 拟合直线，输出斜率、截距、R²、残差标准差，并在散点图上同时标注回归线与相关系数。
- **结论**：投入成本与产出收益 r=0.976（p<0.001），R²=0.953，回归式 y=37.42+1.98x，投入每增加 1 单位产出约增加 1.98 单位。

### 2.7 趋势分析（`07_趋势分析.py`）

- **内涵**：看长期方向（趋势）、短期波动（季节/周期）与异常点，常用折线图加同比/CAGR。
- **迁移**：教材源表是“表头 + 多段数据”的排版，用 `header=None` 按行号切片；年度序列计算 CAGR 并标注峰谷，周处理时长按要求画 11 周柱形。
- **结论**：2014 年 390 单、2024 年 446 单，CAGR 1.35%；峰值 477（2022）、谷值 226（2023），2023 年同比 −52.6% 后 2024 年反弹。

### 2.8 对比分析（`08_对比分析.py`）

- **内涵**：同类对象横向比较，注意排序、基准线与标签可读性；类别名过长时要换横向条形或截断。
- **迁移**：产品订单对比、长名称产品排序（横向条形避免标签重叠）、顾客画像多因素对比（雷达图）。
- **结论**：长名称类别在纵向条形下会重叠，改成横向排序条形后可读性显著提升——这也是教材强调的“图表选择服从数据形态”。

### 2.9 构成分析（`09_构成分析.py`）

- **内涵**：看各部分占整体的比例及其变化，常用堆叠柱、占比条、结构变化对比。
- **迁移**：三张源表分别对应单期占比、两期结构、结构变化；把占比计算封装成 `to_share()`，标题中的百分比由数据动态生成，避免写死。
- **结论**：主导产品占比过半，第二梯队结构在两年间发生位移；结构变化对比图直接标出升降百分点。

### 2.10 分布分析（`10_分布分析.py`）

- **内涵**：看集中趋势、离散程度、偏态与异常值，直方图 + 描述统计是标准组合。
- **迁移**：输出样本量、均值、标准差、分位数、IQR、上下界、异常值个数、偏度；对年龄与客单价分别作图。
- **结论**：客流量在午后形成高峰，年龄集中在 30–45 岁，客单价右偏并存在高价异常值。
- **数据问题**：源表“客单价”列错位存放了下一行的年龄（一致率 >99%），脚本自动识别并打印提示，分布改用正确列计算。

### 2.11 关系分析（`11_关系分析.py`）

- **内涵**：按变量类型选择方法——分类×分类用卡方与 Cramér's V，分类×连续用方差分析，连续×连续用相关与回归。
- **迁移**：三个案例分别做卡方检验（含列联表与堆叠占比图）、单因素方差分析、Pearson 相关与回归，统一输出统计量、p 值与强度指标。
- **结论**：活动与下单 χ²=160.08（V=0.222），忠诚度与满意 χ²=159.18（V=0.324），活动类型对金额 F=363.22（p<0.001），投入产出 r=0.976。

### 2.12 桑基图（`12_桑基图.py`）

- **内涵**：用带宽表示流量，展示页面之间的流转与流失。
- **迁移**：matplotlib 没有原生桑基，脚本自行计算节点层级、按目标节点排序减少交叉，用三次贝塞尔曲线绘制流量带，并按根节点着色。
- **结论**：首页是主要入口，商品页到下单页的转化带最窄；源数据中“博客页面”流出 270 大于流入 250，属于数据不守恒，已在输出中标注。

### 2.13 统计制图原理（`13_统计制图原理.py`）

- **内涵**：教材用反例讲图表的误导性：双轴放大虚假相关、饼图难比较、分面小图优于一张多色折线。
- **迁移**：同一份销售数据画三组对照——双轴“坏例子”与分面“好例子”、饼图与排序条形、2×2 分面小图。
- **结论**：双轴会让两条本不相关的曲线看起来同步；4 个市场应分面展示，而不是塞进一张图。

## 3. 第 10 章 效应分解与预测

### 3.1 乘法效应分解（`ch10/01_乘法效应分解.py`）

- **内涵**：时间序列 Y = T × S × I，先分离趋势与季节，再预测；教材用 Excel 做 12 期中心移动平均与季节指数。
- **迁移**：
  1. 12 期中心移动平均（首尾各半权重）得到趋势 T；
  2. Y/T 得到季节比率，按月份平均并归一化（Σ=12）得到季节指数 S；
  3. 对 T 取对数做线性拟合（与乘法模型一致），趋势外推后乘季节指数；
  4. 用 1949–1959 建模、1960 回测，计算 MAPE。
- **结论**：季节指数夏季最高、冬季最低；1960 年回测 MAPE 9.35%；1961 年全年预测合计 6,860 千人，7–8 月为峰值。
- **注意**：趋势若用线性拟合会低估后期增长，改用对数线性后与乘法结构一致，预测更贴近教材结果。

### 3.2 节日效应与七日预测（`ch10/02_节日效应与预测.py`）

- **内涵**：日消费受星期与节日双重影响，用回归把节日效应从星期效应中剥离，再预测未来 7 天并给区间。
- **迁移**：`statsmodels` 拟合 `amount ~ t + C(wd) + 节日`，输出系数表；预测用 `get_prediction().summary_frame(alpha=0.05)` 得到 95% 预测区间；另外复现教材的“调整后序列”并计算 z 分数与相关系数。
- **结论**：节日效应 +45.42 万元（p=1.8e-12），R²=0.919；星期效应均不显著（p>0.33）；七天预测在周末抬高、区间随预测期变宽。
- **注意**：教材 `credit_card_adjusted.xlsx` 与原始 `pos` 表口径不同（与原始序列相关系数 −0.21），因此只做定性对照，不做数值复现。

## 4. 第 11 章 数据治理

### 4.1 数据质量评估与 DCMM（`ch11/01_数据质量评估.py`）

- **内涵**：数据质量按完整性、唯一性、有效性、一致性、准确性、及时性六个维度量化；DCMM 从 8 个能力域评估数据管理成熟度（1–5 级）。
- **迁移**：教材未提供第 11 章数据，改用第 1 章的 7 张银行表与商场事实表做 34 项真实检查：每项记录检查记录数与问题记录数，按检查记录数加权得到维度得分；DCMM 按 8 个能力域逐条给出评分依据。
- **结论**：完整性 99.39%（`order.k_symbol` 空值 1,379/38,826）、准确性 99.98%（4/12,960 条销售额与数量×单价不符），唯一性/有效性/一致性/及时性均为 100%；DCMM 自评数据质量 4 级，数据架构、数据应用、数据标准 3 级，其余 5 个能力域 2 级。
- **注意**：DCMM 是课程练习的自我评估，不是认证结论；评分依据写的是本项目实际做的事。

## 5. 第 12 章 数据建模

### 5.1 维度建模进阶（`ch12/01_维度建模.py`）

- **内涵**：维度建模的四件事——声明事实粒度、选择星型或雪花、处理缓慢变化维（SCD2）、区分度量可加性。
- **迁移**：
  1. **粒度**：声明“一行 = 某城市某产品某一天的销售”，用三字段组合验证唯一性（0 重复）；
  2. **星型 vs 雪花**：产品维拆成 产品 → 品牌 → 类别，同一口径查询结果用断言校验完全一致；
  3. **SCD2**：为调价产品生成“版本号 + 生效日期 + 失效日期 + 是否当前”，事实按订单日期做区间连接，`assert` 保证每行恰好匹配一个版本；
  4. **可加性**：对比单价简单平均与“销售额/数量”的加权平均。
- **结论**：星型与雪花查询结果完全相同（只是 join 次数不同）；SCD2 只影响调价生效后的订单（A001 +200 元 → +181.4 万元，B001 −150 元 → −79.2 万元）；单价简单平均 4,257 元 ≠ 加权 4,295 元。
- **注意**：源数据两年内单价未变，两次调价是演示用模拟变更，输出表已标注；重算基准取“原价 × 数量”，以避开源表 4 条金额录入误差。

## 6. 第 13 章 指标管理

### 6.1 数据标准、指标标准与指标树（`ch13/01_指标字典与指标树.py`）

- **内涵**：数据标准回答“这个字段叫什么、什么含义、谁负责”；指标标准回答“这个指标怎么算、依赖什么”；指标树把根指标与派生指标分层管理，避免同名不同义。
- **迁移**：
  1. **数据标准体检**：22 个字段的填写率、编号规则（2 位主题码 + 6 位流水）、编码型标准是否给出代码规则、管理负责人与确认情况是否为空；
  2. **标准分布**：读取教材交叉表，核对主题合计与部门合计一致（2,011 项），画主题/部门分布；
  3. **指标标准体检**：编号 `DZ-[A-Z]-3 位流水`、指标类型合法性、派生指标必须有口径与关联标准、生效日期；
  4. **维度与值域**：维度编号 `PA-3 位`、同维度值域编码唯一、值域是否挂靠到已定义维度；
  5. **指标引擎**：用商场事实表把指标真正算出来，输出整体/年度/城市三种口径，并验证派生指标不可加。
- **结论**：客户主题编号 `CM000001` 合规，但“编码型”标准未给代码规则、管理负责人与确认情况为空；两条指标标准（`DZ-G-014` 根指标、`DZ-P-121` 派生指标）全部通过；值域表使用的 `AC0001` 未在维度定义（PA-013~PA-016）中登记；指标结果：销售额 4.10 亿元、单均价 4,295 元、毛利率 45.33%，城市单笔金额简单平均 30,469 元 ≠ 按记录数加权 31,645 元。
- **注意**：源表没有客户号与订单号，“单笔金额”以一次购买记录近似客单价，该口径已写入指标血缘表。

## 7. 复核方式

```bash
py run_all.py
```

- 21 个脚本、40 张图、65 张表，全部可从 `data/` 原始数据重新生成；
- 每张表都在控制台打印了关键结论，图与表的文件名以章节号开头，便于与本文对照；
- 数据口径的异常点在脚本中有提示、在 README 的“数据口径提示”中集中列出。
